## 🏗️ **System Architecture**

### **Frontend Architecture**
```
src/
├── components/          # Reusable UI components
│   ├── auth/           # Authentication forms
│   ├── dashboard/      # Dashboard widgets
│   ├── layout/         # Navigation, headers
│   └── ui/            # Basic UI elements
├── context/            # React Context providers
│   ├── AuthContext.jsx      # Demo authentication
│   ├── AppContext.jsx       # Global state
│   ├── ModalContext.jsx     # Modal management
│   └── ToastContext.jsx     # Notifications
├── pages/              # Main application pages
│   ├── ComprehensiveDashboard.jsx  # 🌟 Main MVP dashboard
│   ├── InfrastructureMap.jsx       # 🗺️  Interactive mapping
│   ├── OptimizationFixed.jsx       # ⚡ AI optimization
│   ├── Analytics.jsx               # 📊 Data analytics
│   └── Home.jsx                    # 🏠 Landing page
└── utils/              # Business logic
    ├── comprehensiveLocalStorageService.js  # 🌟 Core data engine
    ├── completeOptimizationEngine.js        # 🧠 Optimization logic
```

## 🚀 **Getting Started (Hackathon Mode)**

### **Instant Setup - No Backend Required!**

1. **Clone and Start**
   ```bash
   git clone https://github.com/Priyanshu-2109/HackOut-25.git
   cd HackOut-25/frontend
   npm install
   npm run dev
   ```

   - Open: http://localhost:5173
